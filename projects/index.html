课程作品

网页与插件

  • 课间 · 待办清单添加与编辑任务，按日期、优先级筛选，导出备份
  • 纸页 · Markdown笔记编辑与预览，搜索笔记，导入和导出 .md
  • 晴窗 · 天气查询查询城市天气和三天预报，需要联网
  • 个人作品集科研与课程项目，项目详情与内容管理
  • 图提取 · ImageGrab商品图片整理工具，安装说明与可操作的示例画廊

阅读与学习

  • 拾页 · 阅读器网页预览TXT、EPUB、目录与阅读位置
  • 知练 · 知识练习分类答题、错题复习、学习统计和个人题目
本地启动与说明

作品集、阅读器预览和知练需要分别启动对应服务。知练在 projects/practice 目录运行 scripts/start.ps1；阅读器网页预览在 projects/reader 目录运行 npm run preview。

待办和笔记的内容保存在当前浏览器。秒哒与线上作品可从各自的平台打开。
