# 知练：软件开发知识练习系统

## 目标与依据

为正在学习软件开发的学生提供“选知识点—答题—看解析—复习错题—查看进度”的完整学习流程。采用10月19日通知的前端、后端、数据库分支。项目方向为软件开发知识练习。

## 必须可用的流程

- 创建本地学习账号、登录和退出。不同账号拥有独立记录。
- 通过主题、难度、关键词筛选题目，支持单选和多选；提交前不能取得正确答案。
- 提交后显示对错、正确答案、知识解析。重复网络提交不能重复计数。
- 错题自动进入复习列表，可重做、写笔记、标记掌握、重新加入复习。
- 学习统计显示真实答题次数、正确率、覆盖题数、待复习数量、知识点分布及最近七天记录。新账号统计为零。
- 创建、修改、归档自己的题目；公共自编示例题只读。修改后的题目不能篡改历史答题快照。
- 导出自己的学习记录为 JSON，不包含密码与会话。
- 刷新和服务器重启后题目、笔记和练习记录仍存在。

## 界面

桌面以侧栏导航和主工作区组织练习、错题、统计、我的题目；手机采用顶部导航，表单纵向排列。题目、选择和解析是视觉中心。空结果说明恢复方法；提交中禁用重复按钮；所有错误可见、可重试，键盘焦点清楚。

内置18道自编软件开发知识题，支持个人扩充题库。答题后展示题目解析。

## 验收

以真实 API + 临时 SQLite 文件检查账号隔离、单/多选判分、幂等、错题/笔记、题目权限、历史快照和重启恢复。浏览器另验登录、答题、错题复习、统计和窄屏布局。源码包排除 .venv、node_modules、.local、数据库和日志。实现进度见PLAN.md。
