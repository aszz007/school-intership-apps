# 拾页阅读器项目约定

真实Windows桌面应用，Electron隔离主进程与React界面。先交付并留存TXT初版，再实现EPUB与目录迭代，不补造历史。功能与验收范围见本项目PRD.md和TESTING.md。

先读PRD.md和TECH_DESIGN.md。每轮功能后运行npm test、npm run build，修改解析或持久化时补相关行为用例。以实际运行结果记录；Node测试和Chrome界面检查不替代Windows桌面验收。

正文和文件元数据是不可信输入，只按文本渲染。禁止正文脚本、远程导航、Node权限与任意路径接口。只处理用户明确选择的书籍；移除仅影响应用副本，不删除原文件。真实用户数据和缓存不上传或打包。

项目目录独立，不改其他课设或科研仓库。版本留存用允许的Git流程或源码快照及哈希，不强推、不清空数据。截图来自真实界面，不能把网页预览说成桌面程序。
