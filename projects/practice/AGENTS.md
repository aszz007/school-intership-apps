# 知练项目约定

本项目对应2026年10月19日公布的自选全栈复杂项目。先读 PRD.md、TECH_DESIGN.md 和 PLAN.md。

使用 Vue 3、FastAPI、SQLite。依赖仅安装在本项目 node_modules 和 .venv；数据库、会话和个人练习导出不进入源码包。开发服务器仅监听127.0.0.1，不擅自部署、创建远程仓库或修改旧项目。

新增数据库字段采用编号迁移，不删除用户数据库或重建清空；API 返回的题目不提前泄露答案。所有用户记录按会话用户隔离，不信任请求传来的 user_id。先通过真实数据库与 HTTP 测试，再检查浏览器交互。

自编演示题明确标注，统计从实际答题生成。普通解析不能称为模型生成；没有真实外部模型调用不展示“AI已接入”。保留旧版本和已提交考核，不自动提交或推送。
